The ME Solar Panel is a placeable AE power generator. It can export power through an AE network, and the top of the full block must have sky access. A block directly above it prevents generation.

## Block Variants

| Variant | Default daytime output | Default nighttime output | Upgrade slots |
| --- | ---: | ---: | ---: |
| ME Solar Panel | 3000 AE/t | 1000 AE/t | 3 |
| ME Data Solar Panel | 5250 AE/t | 1750 AE/t | 5 |

The ME Data Solar Panel has a **1.75x** base-generation multiplier. The configured daytime and nighttime values can be changed in the solar-panel settings; the default nighttime value is one-third of the daytime value.

## Adjacency And Shared Storage

Cardinally adjacent full solar-panel blocks, including mixed ordinary and data variants, form a horizontal visual and energy array. The blocks do not become one machine and each member generates only once.

- Each block keeps its own AE network node and persisted local energy cell.
- The array exposes a temporary shared storage view, then exports generated energy to available AE networks.
- If an array reaches multiple AE networks, it rotates between distinct networks so a full or offline port does not permanently block the others.
- Chunk unloads, block removal, and connection changes rebuild the array view without duplicating or losing persisted energy.
- Mixed ordinary and data arrays are allowed, but each member keeps its own generation multiplier, upgrade slots, and installed upgrades.

Solar-panel parts attach to a face of an AE2 block or machine and use that face's AE network connection. Generation depends on the attachment direction:

- A part on the top face uses the full base generation value.
- A part on a horizontal side generates `2/3` of the top-face amount.
- A part on the bottom face does not generate.
- Outside special dimensions, the outward face of the part must have sky access.
- The End and AE2 spatial storage use the nighttime base value and do not require normal daytime; other dimensions still use their world day/night state and sky visibility.

Default values:

| Variant | Top daytime | Top nighttime | Side daytime | Side nighttime |
| --- | ---: | ---: | ---: | ---: |
| ME Solar Panel Part | 3000 AE/t | 1000 AE/t | 2000 AE/t | 666.67 AE/t |
| ME Data Solar Panel Part | 5250 AE/t | 1750 AE/t | 3500 AE/t | 1166.67 AE/t |

Parts do not form a shared-storage array with other parts. Each part buffers energy locally and exports it through its own AE2 network node.

## Generation Formula

Speed-card bonuses and the panel's base generation multiplier are multiplicative:

`final generation = base generation × (1 + speed-card count × 0.75) × facing multiplier × data-variant multiplier`

- The facing multiplier is `1` for a full block and a top-mounted part.
- The facing multiplier is `2/3` for a horizontal side-mounted part.
- The facing multiplier is `0` for a bottom-mounted part.
- The data-variant multiplier is `1.75`; the ordinary multiplier is `1`.

## Redstone Control

The solar-panel screen provides a redstone-control toggle:

- **Ignore redstone**: always attempt to generate power.
- **Generate only while receiving a redstone signal**: pause generation without a neighboring signal and resume when a signal is present.

Redstone control only pauses generation; it does not clear stored AE. Existing stored energy remains available to the AE network while generation is disabled.

- <ItemLink id="ae2:energy_card" />: each card adds `80000 AE` to maximum storage; the base capacity is `160000 AE`.
- Ordinary variants and parts have 3 upgrade slots; data variants and data parts have 5.
- The implementation counts installed upgrades and refreshes capacity and displayed generation when upgrades or configuration change.
