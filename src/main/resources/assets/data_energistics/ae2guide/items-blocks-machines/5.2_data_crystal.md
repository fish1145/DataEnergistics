## Data Crystal Parent Rock/Block
 Like Setus Quartz, it comes with meteorites in the universe.   
 You can find it inside the fallen AE digitized meteorite.  
 Charged Data Crystal Motherrock has a 27% chance to generate in groups of 1-2 inside a meteorite.
