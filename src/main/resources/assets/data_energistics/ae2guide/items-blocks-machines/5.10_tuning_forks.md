# Tuning Forks

Place exactly one tuning fork directly above a Tuning Fork Base. A fork cannot remain supported by another block, and it drops with its current damage when its base is removed.

## Base and network requirements

Install one Resonance Digitalization Core by using it on an empty base. Sneak-use the base with an empty hand to remove the core. Breaking the base also returns the installed core.

The base is a normal AE network device and consumes one channel. It can produce Echo only while its node is online, has a channel, contains a core, and its ME network can accept Echo. The base has no internal Echo buffer.

## Yield and durability

| Fork | Maximum durability | Warden sonic boom | Sensor-path or active wave | Chance for a normal wave |
|---|---:|---:|---:|---:|
| Amethyst Tuning Fork | 500 | 5 Echo | 3 Echo | 75% |
| Data Tuning Fork | 1,000 | 10 Echo | 5 Echo | 75% |
| Resonance Tuning Fork | 3,000 | 15 Echo | 8 Echo | 75% |

A direct Warden sonic boom uses the guaranteed Warden yield and processes only the first fork on that ray. A vibration travelling toward a normal or calibrated sculk sensor, and a Resonance Crystal Block's active wave, use the 75% normal-wave rule.

Every eligible hit consumes one durability before the result is known. Durability is still consumed when the chance fails, the core is missing, the base is offline or lacks a channel, or the network accepts no Echo. The last hit completes its current sound and insertion result before the broken fork drops at maximum damage.

Network insertion can be partial. Any positive inserted amount counts as a successful interception; the unaccepted remainder is lost. When one sound is travelling independently to several sensors, each sensor path performs its own interception, so the same fork can lose durability more than once.

Damaged forks retain their damage when mined, stored in a chunk, and placed again. Combine two forks of the same kind in the crafting grid or an anvil to repair them. Crystals are not repair ingredients.
