# Trinity Unit

The Trinity Unit is a replaceable functional unit for the Trinity Data Core. Install it in the matching structure slot and use it as a Digital Storage Core, Digital Merged-Storage Core, or Pattern-Processing Core. An empty unit provides no capacity, so it can be installed while the structure is being built and upgraded later.

## Digital Storage Cores

Digital Storage Cores provide standard ME storage capacity to the main structure. There are ten tiers from 1K through 256M, following the AE2 capacity progression. The 1K and 256K cores are made in the Data Reassembler; the other tiers are crafted in a crafting table.

## Digital Merged-Storage Cores

Digital Merged-Storage Cores combine ME crafting storage with digital storage. They provide crafting storage and virtual crafting CPUs to the CPU child structure. The ten tiers run from 1K through 256M; the 1K and 256K cores are made in the Data Reassembler, and the other tiers are crafted in a crafting table.

## Pattern-Processing Cores

Pattern-processing cores are installed in the crafting child structure to host and execute patterns. There are three tiers, all made in the Data Reassembler.

### ME Digital Pattern Processing Core

Provides 72 pattern input slots for the Trinity structure.

<ItemImage id="data_energistics:me_digital_pattern_processing_core" scale="6" />
<RecipeFor id="data_energistics:me_digital_pattern_processing_core" />

### Extended ME Digital Pattern Processing Core

Provides 144 pattern input slots for the Trinity structure.

<ItemImage id="data_energistics:extended_me_digital_pattern_processing_core" scale="6" />
<RecipeFor id="data_energistics:extended_me_digital_pattern_processing_core" />

### Overlimit ME Digital Pattern Processing Core

Provides 576 pattern input slots for the Trinity structure. This capacity is provisional and may be halved in a future update.
