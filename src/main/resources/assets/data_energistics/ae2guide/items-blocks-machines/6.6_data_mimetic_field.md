> Only three Data Carrier that have already been recorded can be included.  
> After the carrier is placed, it automatically generates corresponding content according to the type.

## Biological Data Carrier

- Recording Object: A certain species
- Role in the Simulation Field: Simulates killing this creature and dropping corresponding items
- Sources of output:
    - Prioritize using configured MOB product rules
    - Otherwise, the creature calls its own loot list
    - If the creature comes with equipment when it spawns, it will also be included in the spawn
    - If the creature has a companion entity, passenger, or mount, it will be counted together

## Mineral Data Carrier

- Record Object: A specific type of ore target
- Role in the Symbiotic Field: Continuous production of corresponding minerals
- Source of Output:
    - Prioritize the use of configured ore product rules
    - If not configured separately, the mineral item will be produced directly by default

## Crop Data Carrier

- Recordable Subjects: Certain crops, saplings, fungi, flowers, sugarcane, cacti, and other recordable plants
- Role in the Growth Field: Continuously produces plants that drop accordingly
- Source of Output:
    - Prioritize the use of configured crop product rules
    - If recording seedlings/propagates, prioritize the corresponding tree loot table
    - If a source block is recorded, it is generated according to the drop table of mature blocks
    - If none of the above results are available, the record itself is generated directly by default
