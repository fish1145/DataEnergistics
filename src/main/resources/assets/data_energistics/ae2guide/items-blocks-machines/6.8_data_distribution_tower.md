# Data Distribution Tower

> Chuunibyou quote: Using data as the measure, this tower will calmly and strictly redistribute connections.

Data Distribution Tower can establish remote AE channel connections for devices within a certain range and actively allocate energy among multiple FE energy containers. It is automatically unfolded by an item, thus classified as a single-block machine.

<Row>
  <ItemImage id="data_energistics:data_distribution_tower" scale="6" />
  <RecipeFor id="data_energistics:data_distribution_tower" />
</Row>

Placement requires **3 blocks** of clear vertical space above the tower base.

Operation can only occur after the tower base is connected to the ME network. The equalizing tower itself requires channels and has dense channel capacity; If a large number of AE devices need to be connected simultaneously, it is recommended to use dense cable access to avoid upstream cables becoming channel bottlenecks.

- Right-click any part of the tower body barehanded: Open the control interface.
- Stealth bare-handed right-click: Switch Range Display.

### Range Adjustment

- **Point-to-Point Connection**: Default mode. Connects only to targets selected with a Distribution Connector.
- **Range Connection**: Automatically scans for eligible devices in range and maintains their connections.

### Connection Targets

- **AE only**: Establish channel connections only for devices with available AE nodes.
- **FE only**: Only devices capable of inputting or outputting FE.
- **AE and FE**: Enable both of these features simultaneously.

AE targets consume channels from the Data Distribution Tower. Once all channels are occupied, remaining targets wait for a channel to become available.

## Distribution Connector

<Row>
  <ItemImage id="data_energistics:data_distribution_connector" scale="6" />
  <RecipeFor id="data_energistics:data_distribution_connector" />
</Row>

The Distribution Connector is used only in **Point-to-Point Connection** mode:

1. Hold the Distribution Connector, sneak right-click Data Distribution Tower, and bind the connector to the tower.
2. Within the same dimension and within the equalizing tower's range, right-click the AE or FE device you want to connect.
3. After a successful connection, the target will appear in the device list on the equalizing tower control interface.

When you place an already bound connector in the offhand or dedicated trinket slot, newly placed compatible devices will also automatically try to connect to that tower.

> Target must be within the equalization tower range and have exposed AE nodes or interfaces capable of receiving FE. Distribution Connector cannot bind goals across dimensions.

## FE energy distribution

Equalizing towers extract energy from devices within range that allow FE output and distribute it to receiving devices with available capacity. The equalizing tower itself does not have a fixed transmission limit per moment; the actual transmission volume depends on the energy source stock and the remaining capacity at the receiving end.

When installing Applied Flux, the splitting tower can also include FE from the network in its allocation. Each target can be individually turned off or resumed in the device list.

## Control Interface

Device List displays target type, location, channel connection, and FE status, and supports search by name or pinyin.

- 'Shift + Right-click' target: Turn off or restore the transmission of this target.
- 'Middle mouse button' target: Highlights targets in the world and displays coordinates.
- 'Shift + Middle Mouse Button' Target: Administrators can teleport directly to the target location.

## Scope of Effect

<Row>
  <ItemLink id="ae2:wireless_booster" />
  <ItemImage id="ae2:wireless_booster" />
</Row>

By default, the tower covers a **1x1 block** area centered on itself. For every **8 Wireless Boosters** installed, one additional ring of blocks is added around it:

| Wireless Boosters | Horizontal range |
| ---: | :--- |
| 0～7 | 1x1 block |
| 8～15 | 3x3 block |
| 16～23 | 5x5 block |
| 24～31 | 7x7 block |
| 64 | 17x17 block |

The vertical range extends **128 blocks downward** and **256 blocks upward** from the tower base, limited by world height.

Expanding the range also increases standby power consumption. By default, a 1x1 block consumes **4 AE/t**, and for each additional block within the range, an additional **8 AE/t** is consumed.
