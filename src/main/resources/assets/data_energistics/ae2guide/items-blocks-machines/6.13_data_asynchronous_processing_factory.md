# Data Asynchronous Processing Factory

The Data Asynchronous Processing Factory is a multi-channel version of the Data Reassembler. It processes multiple Data Reassembler recipes asynchronously in one machine and directly accepts AE2 processing patterns. It supports this mod's Data Reassembler recipes and compatible recipes provided by installed mods.

## Recipes And Processing

### Optional Mod Recipes

The machine executes Data Reassembler recipes: `data_energistics:data_reassembler`.

When the corresponding mod is loaded, the factory converts third-party recipes into processable internal recipes:
- Extended AE crystal assembler recipes;
- Advanced AE reaction chamber recipes.

These recipes are scanned again after a server recipe reload. Without the corresponding mod, the machine still loads normally. Item, fluid, and generic-resource outputs from third-party recipes are sent to the matching factory output slots.

### Processing Patterns

The machine implements the AE2 crafting-machine interface and accepts processing patterns. After a pattern is uploaded, its item, fluid, and resource-key inputs are written to the corresponding factory input buffers, and the pattern output is processed.

The Data Asynchronous Processing Factory uses input colors to distinguish concurrent patterns: once a pattern is assigned to a channel, its inputs retain that color so another channel cannot take them accidentally. To run multiple channels at once, submit separate processing patterns and make sure input and output capacity is sufficient.

> Saber Energy Card: final parallelism = base parallelism × card count × 16, with up to 2 cards.
>
> Speed Card: final duration = base duration - (card count × 40 ticks), with up to 4 cards.

Therefore, with sufficient resources and output space, the machine can run at most three channels at once.<br>
Each channel can also complete multiple parallel operations at a processing boundary.<br>
Actual throughput depends on recipe materials, fluids, resource keys, output slots, and automatic export speed.
