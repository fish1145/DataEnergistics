# Echo

Echo is a stateless AE resource created by capturing a Warden's sonic boom. It uses the vanilla Echo Shard icon for display, but it is not an item or an Echo Shard.

## Capturing Echo

When a Warden fires a sonic boom, the capture ray starts at the Warden's chest, passes through the target's eyes, and continues another 7 blocks beyond the target.

- Ordinary blocks do not obstruct the capture ray, and the original sonic-boom damage is not cancelled.
- A formation plane captures Echo only when the ray crosses its front face, its node is online, and it is connected to an AE grid.
- Each physical formation plane is counted separately by block position and mounted face. Every qualifying plane inserts exactly 1 Echo, including multiple planes on the same network.
- The complete insertion is simulated before it is committed. If the network cannot accept the full unit, no Echo is created, dropped, or cached.
- Capture never force-loads chunks. A failure at one plane does not stop other intersected planes from being checked.

## Storage

A digital storage depot can store Echo in its generic-key slots. An Infinite Data Cell exposes `Long.MAX_VALUE` Echo alongside its infinite Data Flow and Data.

Ordinary item cells, fluid cells, and Data Flow storage cells do not gain Echo capacity. Echo uses 1 unit per storage byte and 1 unit per operation.
