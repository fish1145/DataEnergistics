# Echo

Echo is a stateless AE resource produced by a tuning fork installed above a powered Tuning Fork Base. It uses the vanilla Echo Shard icon for display, but it is not an item or an Echo Shard.

## Production boundary

Formation planes no longer create Echo. Echo enters the world only through the three tuning-fork variants. A fork can react to a Warden sonic boom, intercept a vibration travelling toward a sculk sensor, or receive an active wave from a Resonance Crystal Block. See the separate **Tuning Forks** and **Resonance Crystals** pages for placement rules, yields, probabilities, durability costs, and propagation warnings.

The base has no Echo buffer. It inserts directly into its connected ME network and can accept a partial amount when the network has limited capacity. Echo that the network cannot accept is not dropped or retained for a later retry.

## Storage

A digital storage depot can store Echo in its generic-key slots. Regular and portable Digital Storage Cells store Echo alongside Data Flow and Celestial Energy, and an Infinite Data Cell exposes `Long.MAX_VALUE` of every Digitalization resource and Data.

Ordinary item and fluid cells do not gain Echo capacity. Echo uses 8 units per storage byte and 1 unit per operation.
