# Data Integrated Charger

The Data Integrated Charger combines AE2 charging, inscribing, data charging, powdering, and crystal growth in one machine. Its left-side machine-mode button selects the active recipe family; the current version no longer uses the old physical module slot.

The machine must be connected to an AE network. It has an internal **160,000 AE** energy cache and refills it from an online network. The front is used for the GUI; the other six directions can connect to the AE network and power system. Processing only advances while the required inputs, fluid, energy, and output space are available.

## GUI And Storage

- **9 item input slots**: a 3 × 3 grid. Recipes may use any distinct input slots; the machine resolves matching slots automatically.
- **6 item output slots**: each slot accepts up to **512 items**.
- **3 fluid input slots**: each slot holds **512,000 mB** of one fluid. These tanks are input-only.
- **6 upgrade slots**: install Speed Cards and Saber Energy Cards here.
- **Progress bar**: shows the current operation progress. Changing mode resets progress but does not clear items, fluids, or upgrades.

The auto-export toggle sends item outputs to adjacent AE generic inventories or item handlers. When enabled, the output-side screen lets you select each of the six directions independently. When disabled, results remain in the output slots.

## Machine Modes

Click the machine-mode button to cycle through **Powder → Crystal Growth → Inscriber → Charger → Powder**. The button tooltip shows the active mode.

### Powder Mode

Powder Mode runs AE2 inscriber recipes that have only a middle input and no top or bottom input, and whose result belongs to `#c:dusts`.

- Consumes one middle input.
- Uses no fluid.
- Does not use an upper or lower press.
- Costs **1,600 AE** per operation by default.

### Crystal Growth Mode

Crystal Growth Mode runs data charge-press recipes. Put Data Corrosion Liquid in any fluid tank. The built-in recipes are listed below; data packs may add more.

| Inputs | Data Corrosion Liquid | Output |
| :--- | ---: | :--- |
| 16 Amethyst Shards + 16 Amethyst Dust | 250 mB | 72 Amethyst Shards |
| 16 Charged Certus Quartz Crystals + 16 Certus Quartz Dust | 250 mB | 72 Certus Quartz Crystals |
| 64 Certus Quartz Crystals | 500 mB | 72 Charged Certus Quartz Crystals |
| 16 Data Dust + 16 Charged Certus Quartz Crystals | 350 mB | 20 Data Crystals |
| 32 Data Dust + 16 Data Crystals | 350 mB | 72 Data Crystals |
| 16 Charged Certus Quartz Crystals + 16 Redstone Dust + 16 Quartz | 50 mB | 72 Fluix Crystals |

Each growth operation costs **1,600 AE** by default and consumes the listed items and fluid.

### Inscriber Mode

Inscriber Mode covers the following recipe families:

1. Normal AE2 and Extended AE inscriber recipes. Circuit-board and powder recipes are routed to their dedicated modes instead of being executed as ordinary inscriber recipes.
2. Data-driven multi-input recipes. The built-in example is `12 Dense Energy Cells + 6 Data Processors + 1 Quantum Entangled Singularity → 1 Data Energy Cell`.
3. Triple-output circuit-board recipes. Two circuit-board materials plus **250 mB Data Corrosion Liquid** produce three copies of the original result; reusable presses remain available.
4. When Extended AE is loaded, supported block-input circuit-cutter recipes are adapted to this mode. Standard block cuts produce 14 results for 1,050 mB Data Corrosion Liquid; crystal cuts produce 5 results for 750 mB.

Normal inscriber, data-driven, and circuit-board operations cost **1,600 AE** by default. Use the JEI/EMI entries with the Data Integrated Charger icon for the exact inputs, catalysts, fluids, and outputs.

### Charger Mode

Charger Mode covers AE2/Extended AE charger recipes, data charger recipes, and direct charging of AE-powered items.

- Normal charger recipes cost **1,600 AE** by default.
- Data charger recipes also draw Data Flow from the AE network. The built-in recipe is `1 Snowball + 100 Data Flow → 1 Ender Pearl`, with a 1,600 AE cost.
- For an item that implements AE energy storage, the machine injects energy from its internal cache. The item moves to the output slot only after it is fully charged. Direct charging consumes the amount of AE actually accepted by the item rather than an additional fixed 1,600 AE.

## Speed And Parallelism

Normal processing has a base duration of **200 ticks**. Each Speed Card removes 40 ticks, up to four cards:

| Speed Cards | Duration |
| ---: | ---: |
| 0 | 200 ticks |
| 1 | 160 ticks |
| 2 | 120 ticks |
| 3 | 80 ticks |
| 4 | 40 ticks |

Saber Energy Cards provide parallel processing, up to two cards:

| Saber Energy Cards | Maximum operations per cycle |
| ---: | ---: |
| 0 | 1 |
| 1 | 16 |
| 2 | 32 |

Parallel processing repeats complete operations that are currently valid. It stops when inputs, fluid, energy, or output capacity are insufficient; incomplete recipes are not consumed.

## JEI/EMI And Patterns

JEI/EMI groups every recipe executable by the Data Integrated Charger into one recipe category and displays the required machine-mode icon. The category includes:

- AE2/Extended AE charger recipes;
- AE2/Extended AE inscriber, powder, and circuit-board recipes;
- data charger recipes;
- data charge-press recipes;
- data-driven multi-input recipes;
- Extended AE circuit-cutter adapters when the mod is loaded.

When a processing pattern is uploaded, its item inputs, auxiliary fluid, and output must match a current server recipe exactly. The machine resolves the required mode from that pattern:

- uploads succeed when the selected mode matches;
- uploads are rejected with the required mode when the machine is in another mode;
- uploads are rejected when a pattern matches multiple modes or no longer matches a current recipe.

Select the mode shown by the recipe-viewer icon before uploading a pattern, and make sure the server has finished loading its recipe data.

## Legacy Saves

Older versions used a physical machine-module slot to select the function. The current version uses the GUI mode button instead. When an old save is loaded, the legacy module is removed and refunded; item inputs, outputs, fluids, and upgrades are preserved.
