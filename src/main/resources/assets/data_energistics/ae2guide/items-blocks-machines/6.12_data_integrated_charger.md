# Data Integrated Charger

The Data Integrated Charger combines the data charger, inscriber, AE2 charger, and crystal-growth workflows in one machine. Put a supported machine module in the module slot to select the operation mode.

<GameScene zoom="6" background="transparent">
  <Block id="data_energistics:data_integrated_charger" x="0" y="0" z="0" />
  <IsometricCamera yaw="205" pitch="25" />
</GameScene>

The `ae2:not_so_mysterious_cube` module enables crystal-growth mode. The machine also accepts AE2 or Extended AE inscribers and chargers, as well as the Data Charger modules.

The item input and output slots accept up to **512 items** per slot. The fluid tank holds **51200 mB**.
