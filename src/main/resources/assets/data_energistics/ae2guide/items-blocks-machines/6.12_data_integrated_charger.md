# Data Integrated Charger

The Data Integrated Charger combines AE2 charging, inscribing, dust processing, and crystal growth in one machine.<br>
Use the **machine mode button** on the left side of the interface to select the operation.

When using a Data Charging recipe, the machine must be connected to an AE network.<br>
Its internal AE energy buffer is **160,000 AE** and is automatically replenished from the online network.

---

## Interface And Storage

Items can be stacked up to **512 items** per slot.<br>
Each fluid slot holds **512,000 mB**.
- **Progress bar**: Shows the current mode's processing progress. Changing modes clears the current progress, but does not clear items or fluids in the input or output slots.

---

## Machine Modes

Clicking the machine mode button cycles through **Dust Processing -> Enrichment -> Inscribing -> Charging**. The tooltip shows the current mode.

### Dust Processing Mode

Dust Processing executes AE2 inscriber recipes with only a center input and no top or bottom inputs, and accepts only recipes whose result belongs to `#c:dusts`.

### Enrichment Mode

Recipes can be added through data packs.<br>
The machine consumes the required amounts of inputs and fluids for each recipe.

### Inscribing Mode

Inscribing mode contains the following recipe families:

Normal AE2 and Extended AE inscriber recipes. Circuit-board and dust-processing recipes are handled by their dedicated machine modes and are not duplicated here.<br>
When Extended AE is installed, circuit-cutter recipes that support block inputs are mapped to this mode.

### Charging Mode

Charging mode contains AE2/Extended AE charger recipes, Data Charging recipes, and direct charging for AE energy items.

- A normal charger recipe consumes **1,600 AE** by default.
- A Data Charging recipe also draws the recipe's required Data Flow from the AE network.
- For items that support AE energy storage, the machine injects AE from its internal buffer. The item moves to the output slot only after it is full. Direct charging consumes exactly the AE accepted by the item and does not charge an additional fixed 1,600 AE.
