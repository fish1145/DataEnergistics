# ME Beam Formers

ME Beam Formers establish real AE2 network connections. There are three forms: the **ME Beam Former** (Part), the **Mega ME Beam Former** (directional block), and the **Omni ME Beam Former** (block). An endpoint connects only to another endpoint of the same form. These are not virtual-channel endpoints of the Data Distribution Tower.

- The ME Beam Former and Mega ME Beam Former use a forward beam with a base range of **64 blocks**.
- The Omni ME Beam Former uses a spherical range with a base radius of **128 blocks**.
- Each endpoint has **3 upgrade slots** and accepts up to three Energy Cards. Each card adds **8 blocks** to that endpoint's range.
- Base idle power is **1 AE/t** for the Part, **2 AE/t** for the directional block, and **4 AE/t** for the Omni ME Beam Former. Each established beam connection on an Omni endpoint adds **1 AE/t** at that endpoint, or 2 AE/t for the pair. This additional cost is not multiplied by upgrades.

| Cards | Directional range | Omni radius | Part / directional / Omni base power |
| ---: | ---: | ---: | ---: |
| 0 | 64 blocks | 128 blocks | 1 / 2 / 4 AE/t |
| 1 | 72 blocks | 136 blocks | 2 / 4 / 8 AE/t |
| 2 | 80 blocks | 144 blocks | 4 / 8 / 16 AE/t |
| 3 | 88 blocks | 152 blocks | 8 / 16 / 32 AE/t |

The distance must satisfy both endpoints' ranges. Upgrading only one endpoint cannot bypass the other endpoint's limit. Nodes use AE2 dense channel capacity; the channel mode and upstream cables still determine actual capacity, including infinite-channel mode.

## Visibility and connections

Full blocks connect to cables at the back; Parts mount on AE2 cables. Directional endpoints must face each other. Solid occluding blocks interrupt a directional beam, while glass and other non-occluding blocks allow it through. Omni endpoints need not face each other and can connect through walls.

Right-click with an empty hand to open the upgrade screen, showing status and range. Sneak-right-click with an empty hand to toggle beam visibility. Hiding either end hides the beam without changing its connection.

The remote endpoint need not be powered before connecting: a new link can supply it from the main network. A power outage affects online status and beam display, not valid connections or their accounting.

Bindings do not force remote chunks to load. A connection becomes unavailable while its counterpart is unloaded and automatically becomes usable again when that endpoint returns. Bindings are retained across temporary unloads and range reductions, so restoring upgrades can make them available again.

## Laser Binding Tool

Sneak-right-click an Omni ME Beam Former with the **Laser Binding Tool** to select it as the source. Right-click another same-dimension Omni former to add or remove the symmetric binding. Reversing the endpoints still operates on the same connection, without duplicate cost. Sneak-right-click air to clear the selected source.

The tool records both position and dimension and rejects cross-dimensional binding. An unloaded source retains its selection with a message; a destroyed source clears the selection. An existing binding can be removed after range upgrades are taken out, without reinstalling the cards first.
