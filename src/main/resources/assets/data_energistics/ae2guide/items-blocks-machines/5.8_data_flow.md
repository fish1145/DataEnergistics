# Data Flow Production

Data Flow is a unique and important resource in Data Energistics. It can currently be produced by two machines.

## 1. Data Extractor

  <IsometricCamera yaw="205" pitch="25" />
</GameScene>
<Row>

The Data Extractor produces Data Flow by simulating player attacks and killing mobs. A weapon can be inserted to increase its damage, while upgrade cards can improve its attack speed, energy capacity, and other attributes.

Data Flow production depends on the weapon's base damage and the number of targets. Attacks consume weapon durability. More simultaneous targets and higher weapon damage both increase production.

## Data Extractor Formula

The default Data Flow formula is:

`Data Flow per cycle = round((100 + Energy Cards × 200 + calculated damage × 20) × (1 + max(0, targets - 1) × 0.25))`

Where:

- Production is 0 when there are no targets.
- Calculated damage is 5 when no weapon is installed.
- With a sword: `calculated damage = round(5 + inherited sword damage + Sharpness bonus)`.
- The Sharpness bonus is 0 without Sharpness; otherwise it is `1 + 0.5 × (Sharpness level - 1)`.
- Capacity Cards limit the target count to `20 + Capacity Cards × 5`.
- The final result is rounded with `Math.round`.

Average production is: `Data Flow per second = Data Flow per cycle ÷ work interval in seconds`.

## 2. Data Sanctum

<Row>
  <ItemImage id="data_energistics:data_sanctum" scale="6" />
  <RecipeFor id="data_energistics:data_sanctum" />
</Row>

When active in Black Hole mode, the Data Sanctum absorbs all blocks and entities, including dropped items, within its operating range to produce Data Flow. The result is exported through the rear port.

> Blocks from base AE2, excluding its add-ons, and Data Energistics machines are immune to absorption.

The Data Sanctum processes one cycle every 10 seconds:

`Data Flow per cycle = 1000 × entities actually consumed + (1000 if at least one block was disintegrated, otherwise 0)`

> Block production is not `1000 × blocks disintegrated`. Whether the machine disintegrates 1 block or 20 blocks in a cycle, the block portion produces only 1000 Data Flow.

Average production is: `Data Flow per second = Data Flow per cycle ÷ 10`.

> Dropped items can also be thrown directly into the black hole at the center to produce Data Flow. Entity consumption currently has no cooldown.
