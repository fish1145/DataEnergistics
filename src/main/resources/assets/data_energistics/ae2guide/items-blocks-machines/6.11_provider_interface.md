# Adaptive Pattern Provider/Extreme Capacity Interface

## Adaptive Pattern Provider

> Junior High School Quotes:  
> Resist, analyze, adapt, and integrate, executing the ontology through inheritance.

The Adaptive Pattern Provider can detect and inherit the type, pattern-slot count, and special behavior of other pattern providers.  
Place a compatible provider in its provider slot to use that provider's rules. Its name and icon will also appear in the ME Pattern Access Terminal.

### Blocks and patches

<Row>

The block form can output crafting ingredients in multiple directions. The part form mounts on a cable and outputs toward the device it faces. Both forms share the same inheritance, pagination, and upgrade rules.

### Upgrade

<Row>
  <ItemImage id="data_energistics:adaptive_pattern_provider_upgrade" scale="6" />
  <RecipeFor id="data_energistics:adaptive_pattern_provider_upgrade" />
</Row>

Hold an Adaptive Pattern Provider Upgrade and right-click a standard AE2 Pattern Provider block or part to upgrade it in place. Patterns, custom names, and configuration are preserved. Each conversion consumes one upgrade item.

> Total pattern slots = pattern slots per provider × providers installed in the provider slot

### Capacity card

<Row>
  <ItemLink id="ae2:capacity_card" />
  <ItemImage id="ae2:capacity_card" />
</Row>

The base of the supply slot can stack 4 supply units, with 4 additional units per capacity card, allowing up to 3 capacity cards to be installed.

| Capacity cards | Maximum providers | Pattern slots with standard AE2 providers |
| ---: | ---: | ---: |
| 0 | 4 | 36 |
| 1 | 8 | 72 |
| 2 | 12 | 108 |
| 3 | 16 | 144 |

> Before changing the provider type or removing a capacity card, remove patterns that exceed the new limit. The interface will try to return overflow providers and patterns to the player.

### Redstone Tuning Card

<Row>
  <ItemLink id="data_energistics:redstone_tuning_card" />
  <ItemImage id="data_energistics:redstone_tuning_card" />
</Row>

After installing a Redstone Tuning Card, you can switch between two modes:

- **Emit on dispatch**: Emits a short redstone pulse whenever a batch of crafting ingredients is sent to the target device.
- **Pulse-triggered request**: On each received redstone pulse, requests the primary output of every pattern that can currently be ordered.

> At very high crafting speeds, adjacent devices may merge consecutive output pulses. Use blocking mode or crafting locks when strict sequencing is required.

## Extreme Capacity Interface

Extreme Capacity Interface is a high-capacity version of the standard ME interface.  
It can store items, fluids, and other AE keys from the ME network in configuration and access them through adjacent devices; Additional Return Slots automatically send input back to the ME network.

### Blocks and patches

<Row>
  <ItemImage id="data_energistics:data_sanctum_interface" scale="6" />

The square shape can interact with multiple adjacent faces; In surface-mount form, it is installed on the cable and only interacts with adjacent devices from the side facing the surface-mount. Both forms use the same paged reserves, Return Slots, and upgrade rules.

### In-place upgrade

<Row>
  <ItemImage id="data_energistics:data_sanctum_interface_upgrade" scale="6" />
  <RecipeFor id="data_energistics:data_sanctum_interface_upgrade" />
</Row>

Right-click the standard ME interface or interface chip Extreme Capacity Interface Upgrade handheld to upgrade it to the corresponding Extreme Capacity Interface in place while preserving the original interface configuration and internal data. Each upgrade consumes one upgrade piece.

### Pagination and Slots

Each page provides **9 configuration/reserve slots** and **18 Return Slots**. By default, the interface has 2 open pages; for each capacity card installed, another 2 pages are opened, with a maximum of 3 storage cards installed.

| Capacity card | Available pages | Configuration/Reserve Slot | Return Slots |
| ---: | ---: | ---: | ---: |
| 0 | 2 | 18 | 36 |
| 1 | 4 | 36 | 72 |
| 2 | 6 | 54 | 108 |
| 3 | 8 | 72 | 144 |

By default, each storage slot and Return Slot can hold **2,048 items** or **2,048 buckets of fluid**. Each Capacity Card also doubles the capacity of every slot:

| Capacity card | Single-slot item capacity | Single tank fluid capacity |
| ---: | ---: | ---: |
| 0 | 2,048 | 2,048 barrels |
| 1 | 4,096 | 4,096 barrels |
| 2 | 8,192 | 8,192 barrels |
| 3 | 16,384 | 16,384 barrels |

> The number of pages and the capacity of each slot are both affected by the capacity card. Before removing the capacity card, make sure that the pages about to be locked and the shrunken slots will not retain important content.

### Active Extraction

After active extraction is enabled, Extreme Capacity Interface continuously reads extractable ME storage, general AE inventory, item containers, or fluid containers from the specified adjacent face, and injects the obtained content into its ME network via Return Slots.

- Block shapes can select multiple Active Pull Sides individually.
- The patch shape can only be extracted from the adjacent block facing the patch.
- When the ME network lacks space, extracted contents remain in Return Slots. Extraction stops when those slots are also full.

Active Pull Sides can be enabled and configured with the interface side buttons, or copied to another Extreme Capacity Interface with an ME Memory Card.
