# 数据充压一体机

数据充压一体机把 AE2 充能、压印、数据充能、压粉和水晶生长整合到一台机器中。机器通过界面左侧的**机器模式按钮**选择处理族，不再使用旧版的“模块槽”。

机器需要接入 AE 网络。内部能源缓存为 **160,000 AE**，会从在线网络自动补充；正面用于打开界面，其余六个方向可连接 AE 网络和能源。机器只有在输入、流体、能源和输出空间都满足要求时才会推进进度。

## 界面与存储

- **9 个物品输入槽**：界面中为 3 列 × 3 行。不同配方的输入可以放在任意输入槽，机器会自动寻找互不冲突的匹配槽位。
- **6 个物品输出槽**：每槽最多堆叠 **512 个物品**。
- **3 个流体输入槽**：每槽容量 **512,000 mB**，每槽可以保存一种流体。流体槽只作为输入，不会产出流体。
- **6 个升级槽**：可安装加速卡和聚能卡。
- **进度条**：显示当前模式的处理进度。模式切换会清空当前进度，不会清除输入、输出或流体。

右侧的自动输出开关可以把输出槽中的物品发送到相邻的 AE 通用库存或物品容器。开启后可以在输出面配置界面中单独选择六个方向；关闭自动输出时，物品会留在输出槽中等待取出。

## 机器模式

点击机器模式按钮会按以下顺序循环：**压粉 → 增产 → 压印 → 充能 → 压粉**。按钮提示会显示当前模式名称。

### 压粉模式

压粉模式执行 AE2 压印器中“只有中间输入、没有上下输入”的粉末配方，并且只接受结果属于 `#c:dusts` 的配方。

- 消耗 1 个中间输入。
- 不需要流体。
- 不使用上下压印模板。
- 每次操作默认消耗 **1,600 AE**。

### 增产模式

增产模式执行数据充压配方，流体必须放入任意一个装有**数据腐蚀液**的流体槽。当前内置配方如下；配方也可以通过数据包扩展。

| 输入 | 数据腐蚀液 | 输出 |
| :--- | ---: | :--- |
| 16 紫水晶碎片 + 16 紫水晶粉 | 250 mB | 72 紫水晶碎片 |
| 16 充能赛特斯石英水晶 + 16 赛特斯石英粉 | 250 mB | 72 赛特斯石英水晶 |
| 64 赛特斯石英水晶 | 500 mB | 72 充能赛特斯石英水晶 |
| 16 数据粉尘 + 16 充能赛特斯石英水晶 | 350 mB | 20 数据水晶 |
| 32 数据粉尘 + 16 数据水晶 | 350 mB | 72 数据水晶 |
| 16 充能赛特斯石英水晶 + 16 红石粉 + 16 石英 | 50 mB | 72 福鲁伊克斯水晶 |

每次增产操作默认消耗 **1,600 AE**，并按配方消耗对应数量的输入和数据腐蚀液。

### 压印模式

压印模式包含以下配方族：

1. AE2 和 Extended AE 的普通压印配方。电路板配方和压粉配方会分别交给本机的专用处理逻辑，不会在这里重复执行。
2. 数据驱动的多输入配方。当前内置的示例是：`12 个致密能量元件 + 6 个数据处理器 + 1 个量子纠缠奇点 → 1 个数据能量元件`。
3. 电路板三倍产出配方。输入 2 个电路板材料，消耗 **250 mB 数据腐蚀液**，输出原配方结果的 3 个；可重复使用的压印模板会保留。
4. 如果安装了 Extended AE，则会把支持方块输入的电路切割器配方映射到本模式。普通方块切割配方会产出 14 个结果并消耗 1,050 mB 数据腐蚀液；水晶切割配方会产出 5 个结果并消耗 750 mB 数据腐蚀液。

普通压印、数据驱动配方和电路板配方每次操作默认消耗 **1,600 AE**。具体输入、模板、流体和结果以 JEI/EMI 中带有数据充压一体机图标的配方为准。

### 充能模式

充能模式包含 AE2/Extended AE 充能器配方、数据充能配方，以及对 AE 能量物品的直接充能。

- 普通充能器配方每次默认消耗 **1,600 AE**。
- 数据充能配方还会从 AE 网络中抽取配方要求的数据流。当前内置数据充能配方为：`1 个雪球 + 100 数据流 → 1 个末影珍珠`，并消耗 1,600 AE。
- 对支持 AE 能量存储的物品，机器会把内部缓存中的 AE 注入物品；物品充满后才会移动到输出槽。直接充能的耗能等于实际接受的 AE，不额外收取固定的 1,600 AE。

## 处理速度与并行

普通处理的基础周期为 **200 tick**。每张加速卡减少 40 tick，最多安装 4 张：

| 加速卡 | 周期 |
| ---: | ---: |
| 0 | 200 tick |
| 1 | 160 tick |
| 2 | 120 tick |
| 3 | 80 tick |
| 4 | 40 tick |

聚能卡提供并行处理，最多安装 2 张：

| 聚能卡 | 每个周期最多完成的操作数 |
| ---: | ---: |
| 0 | 1 |
| 1 | 16 |
| 2 | 32 |

并行只会重复执行当前模式中已经满足条件的完整操作；输入不足、流体不足、能源不足或输出槽没有空间时，机器会停止继续处理，不会消耗不完整配方。

## JEI/EMI 与样板

JEI/EMI 会把数据充压一体机能执行的配方集中到统一的“数据充压一体机”分类中，并在配方右上角显示对应模式图标。分类包含：

- AE2/Extended AE 充能配方；
- AE2/Extended AE 普通压印、压粉和电路板配方；
- 数据充能配方；
- 数据充压配方；
- 数据驱动的多输入配方；
- 已加载 Extended AE 时可用的电路切割器适配配方。

使用处理样板上传到数据充压一体机时，样板输入、辅助流体和输出必须与当前服务器配方完全匹配。机器会根据样板自动判断所需模式：

- 样板匹配当前模式时允许上传；
- 样板需要其他模式时拒绝上传并提示需要的模式；
- 样板同时匹配多个模式或已经不再匹配当前配方时拒绝上传，避免机器选错配方。

因此，上传样板前应先切换到配方右上角显示的模式，并确保服务器上的配方数据已经完成加载。

## 旧存档说明

旧版本曾经使用物品模块槽选择机器功能。当前版本已经改为界面模式按钮；读取旧存档时，旧模块会从机器中取出并退还，输入、输出、流体和升级内容会保留。
