# 数位化模式武器

> 中二小语录：
一把将凝聚的物质发射出去的弩，力与美的协奏曲，在空中划出文明最暴力的弧线。

<Row>
    <ItemImage id="data_energistics:dark_string_data_settlement_tool" scale="4" />
    <RecipeFor id="data_energistics:dark_string_data_settlement_tool" />
</Row>
耐久为20kae，可将各色物质球、奇点、满电无升级数据光剑作为弹药。

## 三种模式

| 模式 | 操作 | 弹体行为 |
|---|---|---|
| 数位化-碎星砾（榴弹炮） | 按住攻击键（默认左键）控制射程，松开即发射 | 有重力，沿炮口预览的弧线飞行 |
| 数位化-晶隙碾（磁轨炮） | 按住攻击键蓄能，松开即发射 | 无重力直射，伤害为满蓄力伤害 × 蓄力百分比 |
| 数位化-熵丝弦（弩） | 保留右键上弦、装填后发射 | 保留原弩的弹药和升级逻辑 |

默认 V 切换磁轨炮，B 切换弩；再次按当前模式的键回到榴弹炮。两种炮械蓄满后等待松开，不会因加速卡自动开火。切换模式、换物品或打开界面会取消蓄力。

榴弹初速度在 0.65 和当前弹药基准速度之间随蓄力变化；磁轨初速度为 `max(8, 基准速度 × 2)`。加速卡仍提高基准速度。炮械关闭追踪以保持指定弹道，普通弹药也不会收取追踪的额外耗电。

榴弹炮还可装入 TNT 方块弹药，包括原版 TNT、AE2 微型 TNT、可配置 TNT 和数位歼灭器，以及其他模组的 TNT 变体。TNT 沿预览弧线飞行，触地、撞墙或击中实体时立即触发自身的爆炸或激活效果，保留原 TNT 的威力、特殊效果和水中规则。切换到磁轨炮或弩后，已存入的 TNT 会保留，但不能发射；切回榴弹炮即可继续使用。

安装龙之研究后，榴弹炮还支持龙堆核心（`draconicevolution:reactor_core`）。弹体使用核心自身模型，触地、撞墙或命中实体时启动满燃料龙堆的原生爆炸：基准半径 350 格，再乘以龙之研究的爆炸倍率。爆炸按原模组流程分阶段计算地形，完成后执行破坏、伤害和特效，不附加引信倒计时；蓄力只控制射程。若龙之研究关闭了大型龙堆爆炸，则沿用其小型爆炸和熔岩喷射行为。

|-----------------------------------------------------------------------------------------|--------------------|-------------------------------------|
| <ItemImage id="ae2:matter_ball" /> 各色物质球                                                | 10                 | 200ae                               |
| <ItemImage id="ae2:singularity" /> 奇点                                                   | 25                 | 200ae                               |
