# ME 光束成型器

ME 光束成型器在两个端点之间建立真实的 AE2 网络连接。端点共有三种形态：**ME 光束成型器**（Part）、**巨型ME 光束成型器**（方块式）与 **全向ME 光束成型器**。端点只能与相同形态互连，三种形态不能混接；它们不是数据均分塔的虚拟频道端点。

- ME 光束成型器与巨型ME 光束成型器使用前方直线光束，基础范围均为 **64 格**。
- 全向ME 光束成型器使用球形范围，基础半径为 **128 格**。
- 每个端点都有 **3 个升级槽**，最多安装 3 张 `data_energistics:card_saber_energy` 聚能卡。每张卡都会使该端点的范围和基础功耗各翻倍。
- 部件、方块式、全向设备的基础待机功耗分别为 **1 / 2 / 4 AE/t**。全向端点的每一条已建立光束连接都会在该端额外增加 **1 AE/t**；一对端点合计增加 2 AE/t，附加功耗不随聚能卡翻倍。

| 聚能卡 | 直线范围 | 全向半径 | 部件 / 方块式 / 全向基础功耗 |
| ---: | ---: | ---: | ---: |
| 0 | 64 格 | 128 格 | 1 / 2 / 4 AE/t |
| 1 | 128 格 | 256 格 | 2 / 4 / 8 AE/t |
| 2 | 256 格 | 512 格 | 4 / 8 / 16 AE/t |
| 3 | 512 格 | 1024 格 | 8 / 16 / 32 AE/t |

距离必须同时满足两端的升级范围；只有一端增加聚能卡，不能越过另一端的限制。节点使用 AE2 致密频道容量，实际可用频道仍由当前频道模式和上游线路决定；无限频道模式也沿用 AE2 的规则。

## 可见性与连接

方块式设备从背面接入网络，部件安装在 AE2 线缆上。直线端点需要互相朝向对方，实体遮挡会中断连接，玻璃等非遮挡方块可以通行；全向端点不要求相向，允许穿墙。

空手右键端点打开升级界面，可查看范围、卡数、功耗和连接数量；全向设备还显示保存的绑定数量。潜行空手右键切换光束显示。任一端隐藏时不绘制该光束，但连接本身和功耗不受影响。

建立连接不要求远端预先通电，因此可以先建立链路，再由主网向远端供电。断电只影响在线状态和光束显示，不删除合法连接，也不通过隐藏或断电减少连接计费。

绑定不会强制加载远端区块。另一端卸载时，连接暂时不可用；该端重新加载后即可恢复。临时卸载或降低范围都不会清除绑定，因此恢复升级后连接可以再次可用。

## 光束绑定器

用 **光束绑定器** 潜行右键一个全向成型器以选定源端；随后右键同一维度内的另一全向成型器，添加或解除双向绑定。反向重复绑定也只处理同一条连接，不重复计费。潜行右键空气清除已选源端。

绑定器同时记录坐标和维度，拒绝跨维度绑定。源区块未加载时保留选择并提示；源设备已经拆除时清除失效选择。移除聚能卡造成超距后仍可解除已有绑定，无需先补回升级卡。

## 合成进度

三种设备均由数据重组器制造，依次升级为 **ME 光束成型器 → 巨型ME 光束成型器 → 全向ME 光束成型器**，分别消耗 **16 / 32 / 64 显化二进制**。光束绑定器使用工作台配方；聚能卡沿用本模组现有配方。
