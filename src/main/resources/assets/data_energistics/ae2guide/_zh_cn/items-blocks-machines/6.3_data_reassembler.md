# 数据重组器
>中二小语录:  
>以数据重组信息碎片，织就窥见未来的智能经纬。
>  
它将作为你本模组最重要的机器之一。陪你走过这个模组单方块机器的一路

合成数据重组器时，数据捕捉球球内⚠⚠⚠必须至少有 8 个数据⚠⚠⚠；合成后会返还数据捕捉球，并扣除 8 个数据。
