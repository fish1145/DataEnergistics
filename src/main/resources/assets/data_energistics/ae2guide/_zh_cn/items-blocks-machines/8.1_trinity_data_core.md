# 三位一体数位化核心

三位一体数位化核心是一套由   
**主结构、CPU 子结构和合成子结构**  
组成的多方块系统。   
三部分必须分别通过结构校验后，主核心才会发布完整的 AE2 存储、合成 CPU 和样板供应能力。

## 三个结构部分

| 结构 | 主要职责 | 可配置核心 |
| :--- | :--- | :--- |
| 主结构 | 提供 AE 存储容量和存储类型容量 | 数据存储核心、空三位一体单元 |
| CPU 子结构 | 提供虚拟合成 CPU、合成存储和线程 | 数据合并核心、空三位一体单元 |
| 合成子结构 | 提供物理样板核心容量 | 数位化样板处理核心、扩展样板处理核心、超限样板处理核心、空三位一体单元 |

空三位一体单元可以占据结构槽位但不提供容量，适合先搭建结构再逐步更换核心。不同结构的核心不能互换：数据存储核心只参与主结构，数据合并核心只参与 CPU 子结构，样板处理核心只参与合成子结构。

## 结构搭建

放置三位一体数位化核心后，打开界面中的**结构搭建器**可以查看三个结构的预览、缺少方块和当前等级选择。搭建器按以下顺序配置：

1. 选择主结构的存储核心等级；
2. 选择 CPU 子结构的数据合并核心等级和重复层数；
3. 选择合成子结构的样板处理核心等级和重复层数；
4. 确认预览无阻挡、缺少方块和未加载区块后执行自动搭建。

主结构只能搭建 1 份；CPU 子结构和合成子结构的重复次数可在界面中选择 **1～12**。自动搭建会进行整体验证，失败时不会把一部分结构当成已完成结构发布。

结构定义会检查方向、层数、核心种类和空三位一体单元。手动搭建后重新打开主核心界面即可查看每个结构的成型状态、匹配方块数量和失败位置。

## 主结构：数据存储

主结构声明 **1,176 个存储核心槽位**。每个数据存储核心按等级贡献总容量和可存储类型数：

| 核心等级 | 单核心容量 | 
| :--- | ---: |
| 1K / 4K / 16K / 64K / 256K | 对应等级容量 |
| 1M | 1,024 KiB |
| 4M | 4,096 KiB |
| 16M | 16,384 KiB |
| 64M | 65,536 KiB |
| 256M | 262,144 KiB |

主结构的总容量等于所有已安装存储核心的容量之和，类型容量等于各核心类型数之和。只有当所有声明槽位都使用最高等级 256M 数据存储核心时，主结构才会获得无限存储容量；空单元或低等级核心都会使其保持为有限容量。

主核心界面可以查看当前存储数量、总容量、类型数量和存储优先级。存储优先级遵循 AE2 规则：数值越低，网络越优先取出；数值越高，网络越优先存入。

## CPU 子结构：并行合成

CPU 子结构使用数据合并核心提供合成存储和虚拟 CPU 分区。重复层数决定可用线程数，当前上限为 **256 个线程**；每个已填充的数据合并核心会贡献对应等级的合成存储容量。

- CPU 子结构至少需要一个有效的重复层和一个有效的数据合并核心；
- 线程数随连续重复层数增加，最高 256；
- 所有 CPU 核心槽位均填充 256M 数据合并核心，且重复层达到最大时，CPU 存储会达到无限配置；
- 有效 CPU 会以多个虚拟合成 CPU 的形式发布到 AE2 网络，资源不会在虚拟 CPU 之间错误均分；
- 结构未成型或主存储不可用时，CPU 不会对外发布。

CPU 子结构状态可在主核心界面查看，包括 CPU 结构状态、子 CPU 数量、合成存储和协处理器信息。

## 合成子结构：样板处理

合成子结构使用三种样板处理核心：

| 样板核心 | 单核心样板容量 |
| :--- | ---: |
| 数位化样板处理核心 | 72 |
| 扩展数位化样板处理核心 | 144 |
| 超限数位化样板处理核心 | 576 |

合成子结构的总样板容量等于所有已挂载样板处理核心容量之和。样板核心按物理槽位保存样板，主核心会将这些槽位聚合为统一的样板目录，并通过信息交换仓向 AE2 发布。

样板核心可以打开独立的样板管理界面。结构拆除、核心替换或样板目录变化期间，系统会锁定旧布局并执行维护；已安装样板、排队输入和待输出内容不会因为一次结构重检而被静默删除。

## 信息交换仓

信息交换仓是三位一体系统的网络交互端点。它必须处于有效的三位一体结构中并绑定到主核心，主核心才会通过它发布存储和合成服务。

信息交换仓有三种模式：

- **存储**：把三位一体存储挂载到 AE2 网络；
- **输入**：把网络输入路由到三位一体存储；
- **输出**：把三位一体存储中的内容推送到网络。

一个结构会维护信息交换仓的独占访问租约，避免多个仓同时代表同一主核心发布重复的网络服务。仓的界面可以查看绑定状态、存储状态、合成 CPU 状态和样板处理状态。

## 样板与合成流程

1. 在合成子结构的样板核心中安装处理样板；
2. 确认合成子结构和 CPU 子结构都已成型，并且信息交换仓在线；
3. 通过 AE2 网络提交合成请求；
4. 主核心根据样板目录和 CPU 分区选择执行路径；
5. 输入由信息交换仓进入三位一体存储，样板核心负责匹配与执行，输出再返回 AE2 网络。

主核心界面提供样板搜索、样板优先级、存储优先级和排队内容回退操作。样板优先级作用于整个三位一体聚合供应器，数值越高，规划时越优先选择。

## 故障诊断与维护

主核心界面会分别显示主结构、CPU 子结构和合成子结构的成型状态、匹配方块数量、失败原因和失败位置。遇到“未成型”时，优先检查：

- 主核心朝向和结构前方是否正确；
- 三个结构的层数和重复次数是否一致；
- 核心类别是否放入正确结构；
- 是否误用了不支持当前结构的核心或缺少空三位一体单元；
- 结构所在区块是否已加载；
- 信息交换仓是否已绑定并在线。

拆除或更换样板核心前，先使用界面中的样板回退和留存物品回退操作。正在排队的输入和待输出物品会优先写回 AE 存储，无法写回时再尝试玩家背包和地面掉落。
