# 数据均分塔

> 中二小语录：以数据为尺，这座塔会用冷静而严格的方式重新分配连接。

数据均分塔以**虚拟分配**方式接管无控制器 AE 子网，并在多个 FE 能量端点之间按容量比例均衡能量。塔与目标始终保留各自的 Grid identity，不会创建物理 IGridConnection，也不会合并 Grid。

<Row>
  <ItemImage id="data_energistics:data_distribution_tower" scale="6" />
  <RecipeFor id="data_energistics:data_distribution_tower" />
</Row>

放置时需要塔底上方连续 **3格** 的空间。

将塔底接入 ME 网络后才能工作。塔自身是普通 REQUIRE_CHANNEL 设备，会真实消耗一个物理频道；虚拟设备不受塔上游线缆的 8/32 频道上限约束。

- 空手右键任意塔身部位：打开控制界面。
- 潜行空手右键：切换范围显示。

### 范围调整

- **点对点连接**：默认模式。只接管通过均分连接器手动指定的锚点。绑定会持久保留，即使之后调整范围也不会自动移除。
- **范围连接**：持续发现范围内没有任何物理连接的单节点 Grid。多节点或已经接线的目标会显示为冲突。

### 连接对象

- **仅 AE**：只为具有可用 AE 节点的设备建立频道连接。
- **仅 FE**：只处理能够输入或输出 FE 的设备。
- **AE 与 FE**：同时启用以上两种功能。

点对点解析锚点六个方向暴露的 AE Capability，并按节点 identity 去重；同一锚点可包含多个子网。合法的无控制器子网会被接管，含 Controller、已归属其他主网或会形成桥接环的子网会被跳过，因此一次绑定可以部分成功。只要求锚点与塔同维且位于绑定范围内；接管后的子网成员可以位于范围外或其他维度。

目标子网保留独立 Pathing，其余 Grid 服务委托主网。每个 REQUIRE_CHANNEL 节点独立申请一个虚拟租约，无频道节点不计费；未获租约的节点保持离线，其他节点仍可上线。关闭一个设备只释放它自己的租约和 FE 参与资格。

频道总容量按 Controller 数量计算：Controller conflict 为 0；无控制器主网为“32 × ChannelMode”；每个 Controller 的六个面都供给频道，包括与其他 Controller 相邻的面；Infinite 模式无限。原生 AE2 Pathing 先分配物理频道，虚拟可租容量为“总容量 - 物理占用”。手动绑定优先于自动绑定，同级按首次申请 FIFO；缩容时按相反顺序回收。

## 均分连接器

<Row>
  <ItemImage id="data_energistics:data_distribution_connector" scale="6" />
  <RecipeFor id="data_energistics:data_distribution_connector" />
</Row>

均分连接器只在**点对点连接**模式下使用：

1. 手持均分连接器，潜行右键数据均分塔，将连接器绑定到该塔。
2. 在同一维度和均分塔作用范围内，右键需要连接的 AE 或 FE 设备。
3. 连接成功后，目标会出现在均分塔控制界面的设备列表中。

将已经绑定的连接器放在副手或专用饰品栏中时，新放置的兼容设备也会自动尝试连接到该塔。

> 锚点必须与塔同维、在范围内，并暴露 AE 节点或任意可输入/输出 FE 的接口。纯输出 FE 设备也可以绑定。连接器不能直接绑定跨维锚点，但锚点所属子网的跨维成员会正常参与。

## FE 能量分配

同一主 Grid 上的所有活动塔每次只执行一份跨维端点快照和一笔均分事务。端点包括塔覆盖范围、手动/自动绑定、已加载的从属子网成员以及 Applied Flux 网络端点；查询前会检查 chunk 已加载，不会强制加载区块。

普通机器端点的均分目标是达到相同的**容量填充比例**，而不是相同 FE 数量。纯输出端点优先供给，纯输入端点只接收，普通双向端点只搬运高于或低于均衡线的部分。Applied Flux 网络作为双向缓存，不以自身容量参与比例水位：普通来源结算后，它会按机器真实可接收缺口补足能量，并吸收普通来源的盈余。执行前会冻结并模拟全部抽取/插入；已平衡时不会产生真实 mutation，异常短写会先补偿来源，无法补偿的 FE 进入塔的隔离能量并记录错误。

安装 Modern Industrialization 后，均分塔会直接识别其有向 MI EU 存储；换算使用 MI 当前服务器配置 `forgeEnergyPerEu`，不足 1 EU 的 FE 余数会在预检阶段保留不动。

## 控制界面

顶部频道信息依次显示总容量、物理占用、虚拟租约和剩余量。设备列表按从属子网节点分别显示“已分配”“等待频道”“已禁用”“等待目标”“冲突”或“桥接错误”，并显示申请/获配频道、失败原因和冻结 FE 状态。

- `Shift + 右键`目标：关闭或恢复该目标的传输。
- `鼠标中键`有坐标目标：在世界中高亮目标并显示坐标。
- `Shift + 鼠标中键`有坐标目标：管理员可直接传送到目标位置。

无坐标逻辑节点归组到绑定锚点，只能单独禁用，不能高亮或传送。

## 作用范围

  <ItemLink id="ae2:wireless_booster" />
  <ItemImage id="ae2:wireless_booster" />
</Row>

默认配置下，均分塔覆盖以塔为中心的 **1x1区块**范围。每安装 **16张无线增幅卡**，范围向四周增加一圈区块：

| 无线增幅卡 | 水平范围 |
| ---: | :--- |
| 0～15 | 1x1区块 |
| 16～31 | 3x3区块 |
| 32～47 | 5x5区块 |
| 48～63 | 7x7区块 |
| 64 | 9x9区块 |

垂直范围为塔底向下 **128格**、向上 **256格**，并受世界高度限制。

扩大范围也会提高待机耗电。默认 1x1 区块范围消耗 **4 AE/t**，范围内每增加一个区块额外消耗 **8 AE/t**。
