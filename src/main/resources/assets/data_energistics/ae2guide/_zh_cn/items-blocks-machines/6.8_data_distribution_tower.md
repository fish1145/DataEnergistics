# 数据均分塔

> 中二小语录：以数据为尺，这座塔会用冷静而严格的方式重新分配连接。

数据均分塔可以在一定范围内为设备建立远程 AE 频道连接，并在多个 FE 能量容器之间主动调配能量。它由一个物品自动展开，因此归类在单方块机器中。

<Row>
  <ItemImage id="data_energistics:data_distribution_tower" scale="6" />
  <RecipeFor id="data_energistics:data_distribution_tower" />
</Row>

放置时需要塔底上方连续 **3格** 的空间。

将塔底接入 ME 网络后才能工作。均分塔自身需要频道，并具有密集频道容量；若需要同时连接大量 AE 设备，建议使用致密线缆接入，避免上游线缆成为频道瓶颈。

- 空手右键任意塔身部位：打开控制界面。
- 潜行空手右键：切换范围显示。

### 范围调整

- **点对点连接**：默认模式。只连接通过均分连接器手动指定的目标。
- **范围连接**：自动扫描作用范围内符合条件的设备，并持续维护连接。

### 连接对象

- **仅 AE**：只为具有可用 AE 节点的设备建立频道连接。
- **仅 FE**：只处理能够输入或输出 FE 的设备。
- **AE 与 FE**：同时启用以上两种功能。

AE 目标会占用均分塔可用的频道。可用频道耗尽后，剩余目标会等待，直到有频道。

## 均分连接器

<Row>
  <ItemImage id="data_energistics:data_distribution_connector" scale="6" />
  <RecipeFor id="data_energistics:data_distribution_connector" />
</Row>

均分连接器只在**点对点连接**模式下使用：

1. 手持均分连接器，潜行右键数据均分塔，将连接器绑定到该塔。
2. 在同一维度和均分塔作用范围内，右键需要连接的 AE 或 FE 设备。
3. 连接成功后，目标会出现在均分塔控制界面的设备列表中。

将已经绑定的连接器放在副手或专用饰品栏中时，新放置的兼容设备也会自动尝试连接到该塔。

> 目标必须在均分塔范围内，并且具有暴露的 AE 节点或可接收 FE 的接口。均分连接器不能跨维度绑定目标。

## FE 能量分配

均分塔会从范围内允许输出 FE 的设备提取能量，并分配给仍有可用容量的接收设备。均分塔本身没有固定的每刻传输上限，实际传输量取决于能量源的存量和接收端的剩余容量。

安装 Applied Flux 时，均分塔也可以将网络中的 FE 纳入分配。每个目标都可以在设备列表中单独关闭或恢复传输。

## 控制界面

设备列表会显示目标类型、位置、频道连接和 FE 状态，并支持名称或拼音搜索。

- `Shift + 右键`目标：关闭或恢复该目标的传输。
- `鼠标中键`目标：在世界中高亮目标并显示坐标。
- `Shift + 鼠标中键`目标：管理员可直接传送到目标位置。

## 作用范围

<Row>
  <ItemLink id="ae2:wireless_booster" />
  <ItemImage id="ae2:wireless_booster" />
</Row>

默认配置下，均分塔覆盖以塔为中心的 **1x1区块**范围。每安装 **16张无线增幅卡**，范围向四周增加一圈区块：

| 无线增幅卡 | 水平范围 |
| ---: | :--- |
| 0～15 | 1x1区块 |
| 16～31 | 3x3区块 |
| 32～47 | 5x5区块 |
| 48～63 | 7x7区块 |
| 64 | 9x9区块 |

垂直范围为塔底向下 **128格**、向上 **256格**，并受世界高度限制。

扩大范围也会提高待机耗电。默认 1x1 区块范围消耗 **4 AE/t**，范围内每增加一个区块额外消耗 **8 AE/t**。
